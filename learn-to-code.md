## Motivation

- It makes you a modern magician
- It's fun to build things
- It pays well
- It enables you to build things that are (nearly) infinitely scalable
- It's hard

## Languages

- `C` is the basis of almost everything else
- `JavaScript` is the basis of almost everything on the web
- and `TypeScript`
- `C#` is very good for a big boy language
- Could also learn `Java` (yuck), `Go`, `Rust`, `C++`
- `Python` for scripting and AI (for now)
- Learn enough `bash` and `PowerShell` to be dangerous
- `Lua`, assuming you're going to use Neovim right away (you should)

### Editor

Learn Vim (or Neovim).
- Consider starting with LazyVim: [LazyVim for Ambitious Developers](https://lazyvim-ambitious-devs.phillips.codes/)

Simple avoids distraction. Customizable molds to your mind and workflow. Minimal improves speed. Modal improves efficiency.

## Philosophies

- Write tests
- Code in pairs (or mob) whenever possible
- Don't lean on AI
